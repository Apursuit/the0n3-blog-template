## 关于本站

这里是「关于」页面的示例内容，可直接修改 `pages/about.md`。

本站使用一个自建的极简静态博客系统：以 Markdown 写作，推送到仓库后由 GitHub Actions 自动构建并部署到 GitHub Pages。

## 项目特点

- 纯 Markdown 写作，front matter 管理文章元信息
- 自动生成首页分页、标签页、分类页、归档页与独立页面
- 分类与标签拥有独立落地页，便于被搜索引擎收录
- 构建期生成 sitemap，`lastmod` 取自 git 提交历史
- 内置代码高亮、Callout 提示块、图片灯箱与全文搜索
- 支持 Giscus 评论，评论区主题跟随站点明暗模式

## 如何开始

参考项目根目录的 `README.md`，按「快速开始」的四个步骤即可在本地运行。

## 说明

本页是独立页面功能的示例之一，与文章一样由 `pages/` 下的 Markdown 文件驱动，但单独管理，不会出现在首页列表与归档中。
